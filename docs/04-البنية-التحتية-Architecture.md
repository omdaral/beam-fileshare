# 04 - البنية التحتية والأساس - Architecture

> الأساس التقني الذي لا يتغير إلا بتحديث هذا الملف. الهدف: ملف واحد، بدون مكتبات على جهاز المستخدم، ويندوز + لينكس.

## 1. القرار التقني النهائي
- **اللغة:** Go (stdlib فقط — بدون أي dependency خارجي) + باينري static واحد لكل نظام.
  - السبب: لا حاجة لـ Python/pip/tkinter على جهاز المستخدم إطلاقاً — يطلع `Beam`
    للينكس و `Beam.exe` لويندوز (أمر `CGO_ENABLED=0 go build`) جواه السيرفر + صفحة الويب.
  - ملاحظة تاريخية: كان التطبيق Python (PyInstaller) ثم استُبدل كاملاً بـ Go —
    أي إشارة لـ Python/PyInstaller/tkinter في هذا الدستور لاغية.
- **السيرفر:** HTTP Server داخلي (Go net/http) على بورت ثابت `2004` — يفتح المتصفح بنفسه عند التشغيل، ويُغلق نفسه بعد 5 ساعات خمول.
- **الواجهات:** HTML + CSS + JS خام مضمنة بـ go:embed (بدون CDN لأننا أوفلاين) + خط Cairo محلي.
- **الديسكتوب:** لا نافذة — التحكم كامل من المتصفح (قسم الإدارة يظهر لجهاز التشغيل فقط).

## 2. المكونات (Modules)
```
Beam(.exe)
├── 1. Hotspot Manager
│   ├── Windows: netsh / PowerShell (Mobile Hotspot API)
│   └── Linux: nmcli device wifi hotspot (NetworkManager)
├── 2. File Server (net/http)
│   ├── GET /         -> صفحة الملفات (دخول مباشر بدون كود)
│   ├── GET /files    -> قائمة JSON
│   ├── POST /upload_init {uuid,name,size} -> بدء/استكمال جلسة {id, offset}
│   ├── POST /upload_chunk?id=&offset= (بايتات خام تُبث للقرص) -> {offset}
│   ├── GET /upload_status?id= -> موضع الاستكمال
│   ├── POST /upload_complete {id} -> تجميع ذري {saved}
│   ├── GET /download?file= -> تنزيل متدفق
│   ├── POST /delete  -> حذف (الكل مسموح — بقرار المستخدم)
│   └── GET /api/status -> حالة الشبكة للواجهة (ssid/security/wifi_password)
├── 3. Browser Admin (نافذة إعدادات Modal — تُعرض لجهاز التشغيل فقط)
│   ├── تبويب الشبكة: اختيار LAN/Hotspot + SSID/باسورد + زر تشغيل/إيقاف
│   ├── تبويب عام: بورت + حد الملف + اللغة الافتراضية للزوار (default_lang)
│   ├── عرض SSID/Bass + QR + IP:Port (لاندنج بيدج للجميع)
│   └── سجل + أجهزة متصلة (تظهر لصاحب الجهاز فقط — أي API إداري يرفض غيره بـ 403)
└── 4. Storage + Lifecycle
    ├── مجلد المشاركة الوحيد: `~/Downloads/Beam` (مكان معروف — لا بلوت وير)
    ├── الإعدادات: ذاكرة الجلسة فقط (+ نسخة localStorage في متصفح المالك) — لا config.json
    ├── السجل: حلقة ذاكرة (آخر 500 سطر في صفحة الويب) — لا logs/
    └── إغلاق تلقائي بعد 5 ساعات خمول + زر ⏻ أحمر بارز في الهيدر للإيقاف اليدوي
```

## 3. الشبكة والـ Hotspot
- **الوضع الأساسي Hotspot:**
  - Windows IP الافتراضي: `192.168.137.1` — Linux غالباً `10.42.0.1` (يتكشف تلقائياً ويظهر في الواجهة).
  - SSID افتراضي: `Beam` — تشفير WPA2 — باسورد 8+ حروف.
  - يتطلب Admin/sudo أول مرة (لإنشاء الشبكة وفتح البورت في الفايروول).
  - كارت الواي فاي لازم يدعم AP Mode — نفحصه عند التشغيل ولو فشل نعرض رسالة + زر LAN Mode.
- **الوضع البديل LAN Mode:**
  - لو الـ Hotspot مستحيل، البرنامج يشتغل على واي فاي الموجودة ويعرض IP الجهاز الحالي + QR.
- **مشاركة الإنترنت:** لو الجهاز الرئيسي متوصل Ethernet، نفعل Sharing (اختياري). لو متوصل WiFi فقط، مشاركة الملفات تظل شغالة بدون إنترنت.

## 4. الملفات والمجلدات (هيكل المشروع الفعلي)
```
تطبيبق مشاركة ملفات/
├── docs/ (دستور المشروع - المجلد ده)
├── goserver/ (سورس Go: سيرفر + هوتسبوت + إدارة + اختبارات + web/index.html مضمنة)
├── Beam / Beam.exe (الباينري المبني لكل نظام — لا يُرفع)
├── Beam.sh / Beam.bat / Beam.command (المشغّل: يشغّل السيرفر لو واقف؛ السيرفر يفتح المتصفح بنفسه)
├── install.sh (يولّد مسارات الأيقونة) + Beam.desktop (الأيقونة — تُولَّد ولا تُرفع)
├── build.sh / build.bat (البناء: go vet + go test + مصفوفة os/arch في dist/ + versions.json)
└── لا config.json ولا logs/ ولا Shared/ — (الإعدادات جلسة فقط، السجل ذاكرة، الملفات في ~/Downloads/Beam)
```

## 5. الأمان (بقرار المستخدم: باسورد الواي فاي هو خط الدفاع الوحيد)
1. باسورد WPA2 قوي للشبكة (12+ حرف موصى به، ويتغير دورياً) — أي جهاز على الشبكة يدخل مباشرة.
2. منع `../` والملفات المخفية في أسماء الملفات (Path Traversal + إخفاء المؤقت).
3. حد حجم الملف الواحد: 20GB افتراضياً (يُغيَّر للجلسة من الإعدادات) — الرفع المقسم لا يحمل الملف في الرام.
4. سجل ذاكرة (آخر 500 سطر في صفحة الويب): مين رفع/نزل/حذف إيه وإمتى (للمراجعة أثناء الجلسة).
5. الكتابة الذرية تمنع تنزيل ملف ناقص أثناء رفعه؛ القفل يمنع فقدان ملف عند تزامن نفس الاسم.
6. الشبكة المفتوحة (لينكس فقط): `wifi_open=true` — بتحذير صريح؛ ويندوز يرفضها برسالة واضحة.
- **مستقبلاً (مش الآن):** حد سرعة لكل عميل + حظر IP + HTTPS داخلي + كود دخول اختياري.

## 6. مراحل البناء (بالترتيب - ممنوع القفز)
1. **المرحلة 1:** سيرفر Go + صفحة ويب (رفع/تنزيل) وتجربته على LAN عادي بدون Hotspot.
2. **المرحلة 2:** موديول Hotspot ويندوز ثم لينكس + عرض QR + كشف IP تلقائي.
3. **المرحلة 3:** إدارة المتصفح (localhost مدير فقط — لا دخول عن بعد) + إعدادات الجلسة + سجل الذاكرة + رسائل الخطأ العربية.
4. **المرحلة 4:** البناء بـ `./build.sh` (لينكس) / `build.bat` (ويندوز)
   + `./install.sh` بعد كل نسخ للمجلد + اختبار 8 أجهزة + ملف README.

## 8. قاعدة ذهبية
أي مكتبة جديدة لازم تكون مدمجة في الملف النهائي ولا تتطلب تثبيت من المستخدم. لو مكتبة تكسر القاعدة -> مرفوضة حتى لو أسهل في الكود.
