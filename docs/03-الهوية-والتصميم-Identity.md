# 03 - الهوية والتصميم - Identity & Design

> الانطباع: لاندنج بيدج جريئة وملونة — هيرو متدرج يملأ الشاشة وسكاشن full-bleed، بهدوء ورقي في المحتوى.

## 1. الاسم والهوية: Beam
- **الاسم:** Beam — شعاع مباشر بين الأجهزة (4 حروف لاتينية عالمية، يُلفظ كما يُكتب).
- **الشعار:** SVG مضمن — 3 حزم ضوئية مائلة + نقطة (جهاز) بلون الشارة. نسخة favicon data-URI.
- **الألوان (فاتح — الافتراضي):**
  - ورقي `#F7F5F0` + أبيض `#FFFFFF` + حبر `#191714` + رمادي دافئ `#6E675C`
  - شارة دولية `#D9481F` (أحمر-برتقالي صريح) + بنفسجي `#8B5CF6` + سماوي `#00B8D4` (للهيرو واللمسات) + نجاح `#1E7B44` + خطر `#B3261E`
- **الألوان (داكن — بمفتاح):** `#141210` + `#1E1A15` + حبر فاتح `#F2EDE3` + شارة `#FF6B4A`.
- **الخطوط (أوفلاين):** Cairo للعربية (400/700/900 مضمنة) + سلسلة grotesk النظامية للاتينية + monospace للروابط والأرقام. العناوين 900.
- **اللغات:** عربي (RTL) + إنجليزي (LTR) — زر الهيدر للجميع (اختيار محلي يُحفظ)، والمالك يحدد `default_lang` للزوار الجدد من تبويب "عام" (تُعلن في `/api/status`). قاموس `STR` واحد نقي (بدون كود)، مفاتيح `data-i18n`.
- **القواعد:** التدرجات مسموحة في الهيرو واللمسات فقط (باقي السكاشن صلبة)، أيقونات SVG خطية بدل الإيموجي نهائياً، حدود hairline، ظل واحد ناعم، `prefers-reduced-motion` محترم.

## 2. اللاندنج بيدج `/` (الكل — والمالك يرى زر ⚙️)
سكاشن بعرض الشاشة (حاوية داخلية 1100px، موبايل أولاً):
1. **الهيرو `#join`:** شارة مباشر + عنوان ضخم + رابط الدخول بخط mono + نسخ + إحصاءات (الشبكة/الأجهزة/الوضع) — للجميع.
2. **شريط 3 خطوات:** اتصل → افتح/امسح → ارفع ونزّل.
3. **الشبكة `#share`:** لوحة المعلومات + لوحة QR (أسود على أبيض دائماً) + نسخ.
4. **نافذة المالك `#ownerZone`** (Modal — زر ⚙️ في الهيدر يظهر لـ localhost فقط، والـ APIs ترفض غيره):
   تبويب الشبكة (LAN/هوتسبوت + SSID/باسورد/مفتوحة + تشغيل/إيقاف + القدرة) + تبويب عام (بورت/حد/لغة افتراضية) + تبويب الأجهزة والسجل (لايف 3 ثوانٍ + تحديث/مسح) + تبويب الجهاز (إيقاف السيرفر).
5. **الملفات `#filesSec`:** الرفع (ملفات/مجلد بمحتوياته) + شجرة قابلة للطي + بحث محلي فوري + تنزيل zip للمجلدات + المجلد المتجاوز للسقف صف zip مع السبب + قسم مساعدة `#help` + فوتر.

## 3. الصوت والنبرة (AR + EN)
- عربي بسيط وإنجليزي مباشر، صيغة فعلية، نفس الاسم للزر والنتيجة.
- الخطأ بصيغة حل + رسائل السيرفر ثنائية (`msg` حسب `X-Lang`، و`Accept-Language` احتياطياً).
- الحالات الفارغة دعوات للفعل. لا مصطلحات تقنية.

## 4. قواعد ملزمة
- كل زر لمس لا يقل عن 48px. ممنوع Popups وإعلانات.
- الـ QR لا يقل عن 200x200px بإطار أبيض، ويُمسح بالموبايل (بوابة قبول).
- ممنوع تسجيل حساب أو إيميل. ممنوع أي زر لا يخدم رحلة المستخدم (ملف 02).

- `goserver/web/qrcode-vendor.js` على `/vendor/qrcode.js`.
