# دستور المشروع - برنامج مشاركة الملفات عبر Hotspot

> هذا المجلد هو **المرجع الوحيد** للمشروع. أي قرار أو تعديل لازم يرجع هنا الأول.
> ممنوع نتوه: لو حاجة مش مكتوبة هنا، نناقشها ونوثقها قبل ما ننفذها.

## المشروع باختصار
برنامج للكمبيوتر (ويندوز + لينكس) يعمل شبكة Hotspot خاصة بالشركة،
وأي موبايل أو كمبيوتر يدخل عليها يقدر **يرسل ويستقبل** ملفات من المتصفح
بدون تثبيت أي حاجة عنده، وبدون إنترنت، وبدون مكتبات.

## القواعد الذهبية (دستور فوق الدستور)

1. **ضغطة واحدة تشغل:** المستخدم العادي مش تقني. تشغيل البرنامج = دبل كليك فقط.
2. **زيرو تثبيت للعملاء:** الموبايلات والكمبيوترات المستقبلة تدخل من المتصفح فقط.
3. **زيرو مكتبات على جهاز المستخدم:** الملف النهائي `exe` / `binary` واحد فيه كل حاجة.
4. **أوفلاين أولاً:** البرنامج لازم يشتغل بدون إنترنت تماماً.
5. **إرسال + استلام:** مش برنامج عرض فقط. الرفع والتنزيل في الاتجاهين.
6. **ويندوز + لينكس:** أي خاصية لازم تشتغل على النظامين أو يكون لها بديل موثق.
7. **أي تعديل = تحديث الدستور:** مفيش كود يخالف الملفات دي. لو لازم نخالف، نعدل الملف الأول.

## المصطلحات الموحدة
- **الكمبيوتر الرئيسي:** الجهاز اللي عليه البرنامج وفاتح الـ Hotspot.
- **العميل:** أي موبايل أو كمبيوتر داخل على الشبكة من المتصفح.
- **LAN Mode:** وضع بديل لو الـ Hotspot فشل، نشتغل على واي فاي الموجود.
